# ❄️ Thor's Notes - English Study Platform

A modern, responsive, and interactive web application designed to help users study English effectively. The platform features dynamic content loading from Firebase, allowing users to explore Vocabulary, Grammar, and Phrasal Verbs in an engaging, distraction-free environment. It also includes a comprehensive Admin panel for managing all study materials.

## 🌟 Key Features

- **Rich Vocabulary Sections**: Organized by units, featuring interactive tabs for Vocabulary, Phrasal Verbs, Prepositional Phrases, Word Formation, Word Patterns, and Lexical Expansion.
- **Grammar Lessons**: Structured grammar materials categorized by topics with detailed explanations.
- **Audio Integration**: Built-in audio players for vocabulary pronunciation.
- **Dynamic Content**: Data is securely stored and fetched in real-time from Firebase Firestore.
- **Responsive Design**: A sleek, modern UI with a clean color palette (soft mint green, dark teal) optimized for both desktop and mobile devices.
- **Admin Dashboard**: A secure, authenticated admin interface to seamlessly add, edit, and manage books, units, vocabulary, and grammar lessons using TinyMCE rich text editor.

## 🛠️ Technology Stack

- **Frontend**: HTML5, Vanilla CSS3 (Custom Design System), JavaScript (ES6+).
- **Backend/Database**: Firebase (Firestore for database, Firebase Auth for admin authentication).
- **Tools**: TinyMCE (Rich Text Editor).



## 🚀 Getting Started

### Prerequisites
- A modern web browser.
- A local development server (like VS Code Live Server) to prevent CORS issues when loading ES modules.
- A Firebase project
